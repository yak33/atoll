# 01 · 产品需求(PRD)

> 状态:v0 草案 · 2026/09/30 · 作者 ZHANGCHAO

## 1. 一句话定位

一个钉在 Windows 屏幕顶部的灵动岛悬浮组件,常驻展示智谱 GLM Coding Plan 的 5h / 7d 滚动用量窗口,接近限额时主动告警,窗口重置时提醒。它是容器,智谱用量只是第一个模块。

## 2. 用户故事

- 作为 GLM Coding Plan 订阅用户,我想随时瞟一眼知道 5h 窗口还剩多少额度,不用开浏览器登官网。
- 接近限额时(75% / 90%),我希望岛主动变色提醒我,避免写代码写到一半被限流。
- 窗口重置后,我希望收到提醒「已恢复」,可以继续高强度使用。
- 我不希望它碍事:平时只是一颗小药丸,不挡内容、不抢焦点、不出现在任务栏。

## 3. 数据展示需求

| 项 | 要求 |
| --- | --- |
| 5h 窗口 | 已用百分比 + 进度条 + 重置倒计时 |
| 7d(weekly)窗口 | 同上 |
| 套餐等级 | 展示接口返回的 `data.level`(如 GLM Coding Plan 档位名) |
| 数据新鲜度 | 显示最后成功查询时间;失败时保留上次快照并标注「过期」 |
| 手动刷新 | 展开态提供刷新按钮(绕过轮询周期,但仍受退避约束) |

**明确不做**(v0 非目标):多账号池、代理、用量计费换算、其他平台适配。架构上留 adapter 位,但产品上只做智谱。

## 4. UI 三态状态机

灵动岛的核心体验是「态」。三个状态,触发条件如下:

```
        ┌──────────────┐  鼠标悬停   ┌──────────────┐
        │  collapsed   │ ──────────> │  expanded    │
        │  (常态药丸)   │ <────────── │  (完整面板)   │
        └──────┬───────┘   鼠标离开   └──────────────┘
               │ 任一窗口 usedPercent 跨过阈值
               v
        ┌──────────────┐
        │    alert     │  (药丸变色+脉冲,悬停仍可展开;
        │  (告警态)     │   阈值回落或窗口重置后退出)
        └──────────────┘
```

### 4.1 collapsed(收起态)

- 尺寸约 260×44,屏幕顶部居中。
- 只显示**最紧张的那个窗口**:取 usedPercent 最大的一档,显示 `5h 43%` + 迷你进度条。
- 收起态本身可显示倒计时(如 `2h 15m`),灰色小字。

### 4.2 expanded(展开态)

- 鼠标悬停触发,药丸横向展开(宽约 420,高约 200),平滑动画 200ms。
- 内容:两档窗口完整进度条 + 倒计时、套餐等级、最后查询时间、手动刷新按钮。
- 鼠标离开后 500ms 延迟收回(防止误触抖动)。

### 4.3 alert(告警态)

| 阈值 | 表现 |
| --- | --- |
| usedPercent ≥ 75 | 药丸变琥珀色 |
| usedPercent ≥ 90 | 药丸变红色 + 轻微脉冲动画 |
| resetAt 剩余 < 5min | 倒计时高亮(即将重置) |
| 窗口重置完成(原 alert 窗口回落到低用量) | Windows toast 通知「5h 窗口已重置」 |

阈值取值与配色沿用业内通行约定(75 琥珀 / 90 红),绿色为正常。

## 5. 倒计时规则

- 倒计时 = `resetAt - 本地时钟`,纯本地计算,每 60 秒跳一次,**不产生网络请求**。
- `resetAt` 已过期但用量 > 0:显示「待刷新」——说明后端快照过期,等待下一次轮询回写,而不是谎报「现在」。
- `resetAt` 缺失(接口未下发):该窗口不显示倒计时,只显示百分比。
- 格式:`3d 9h` / `2h 15m` / `14m`,超过 24h 显示天。

## 6. 行为需求

| 场景 | 行为 |
| --- | --- |
| 开机自启 | 默认开启,可在设置中关闭(M3) |
| 全屏应用前台 | 岛自动隐藏,退出全屏恢复(M3) |
| 鼠标穿透 | 收起态下岛外区域点击穿透到下层窗口(M3,悬停岛时恢复接收) |
| 多显示器 | 钉在主显示器顶部(M3 确认行为) |
| 数据源不可达 | 保留最后一次快照,显示「过期 X 分钟」,按退避重试 |

## 7. 凭据与安全

- 智谱 API Key 由用户在设置界面手填,存储在本机(M1 定:localStorage 或 Tauri store,见架构文档)。
- Key 绝不写入日志、绝不出现在错误提示文案中。
- 团队版用户额外填组织 ID(可选项目 ID),用途见接口文档。
