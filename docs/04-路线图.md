## 后续模块方向(灵动岛容器扩展位)

仅记录方向,不承诺排期;每个模块遵循「独立 adapter/服务 + 独立 UI 卡片」的容器模式:

- Claude / Codex 用量窗口(本地凭据文件 + 官方 usage 接口,需处理 token 刷新)
- Claude 重置卡余量展示与消耗(官方 cedar_ember 接口)
- 通用:全局快捷键、剪贴板历史、番茄钟、系统监控小卡
