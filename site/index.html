智谱用量监控

直连智谱官方额度接口，读 5 小时与 7 天两个滚动窗口的已用百分比和下次重置时间。

  • 倒计时纯本地计算，不产生任何网络请求
  • 每 5 分钟拉一次，带随机抖动，失败按 1 到 10 分钟指数退避
  • 接口是非公开文档的，字段可能变：全部容错集中在适配器一层
  • 团队版组织 ID 与项目 ID 已支持

番茄钟

工作阶段走完自动进休息，反向同理，每次切换发一条 toast。时长在设置里拖滑杆，5 到 60 分钟。

  • 计时基于结束时间戳，不累加 tick，所以窗口被隐藏导致定时器节流也不会跑偏
  • 检测到系统休眠会冻结在断点前并自动暂停，回来后你手动继续
  • 运行中改时长不打断当前阶段，下一阶段才生效

它的首要职责是不碍事。

在你不看它的时候

全屏自动隐藏。检测到前台窗口铺满显示器就让灵动岛消失，退出全屏自动回来。打游戏、看片、投屏演示时它不占位置。

不进任务栏，不抢焦点。无边框透明置顶窗口，平时只是屏幕顶部一条 44 像素的胶囊。

托盘控制与实时监控。想彻底藏起来，托盘菜单一键显示或隐藏；鼠标悬停托盘图标即可看实时用量与番茄倒计时。

在你需要它的时候

拖到哪算哪。默认主显示器顶部居中，按住面板任意位置就能移动，位置记在本地，下次启动回到原处。

主题与质感皮肤。浅色、深色、自动三档；内置黑曜石、深海蓝、极光紫、赤焰橙、薄荷绿、钛金金 6 款调优质感皮肤，强调色与微光实时联动。

开机自启。默认关闭，设置里一键打开。

Tauri 2 + Vue 3，没有后端。

API Key 存在本机应用数据目录，请求经 Rust 侧发出以绕开 WebView 的同源限制，域名白名单收紧到智谱两个站点。
